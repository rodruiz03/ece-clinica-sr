# ADR-001: Selección de framework backend/frontend

**Estado:** Aceptado
**Fecha:** 2026-08-31

## Contexto
El equipo necesita un stack productivo, con curva de aprendizaje baja para un
equipo de 8 personas y un MVP en 6 meses.

## Decisión
- Backend: Node.js + Express.
- Frontend: React.

## Consecuencias
- Ecosistema JavaScript unificado entre frontend y backend.
- Amplia disponibilidad de librerías y documentación.
- Facilita el testing con Jest en ambas capas.
